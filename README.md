# Daily Do Gehoortraining

Gehoortraining van do tot do, met pianoklanken.

- **Noten** – de acht noten apart beluisteren, en raden welke noot je hoort vanaf een vertrekpunt
- **Daily Do** – meespelen en meelezen op de notenbalk, tempo instelbaar tot 100 bpm
- **Intervallen** – prime, secunde, terts, kwart, kwint, sixt, septiem en octaaf herkennen
- **Melodisch dictee** – noten op de notenbalk zetten, op basis van je gekende noten

Alles zit in `index.html` (de pianonoten zijn erin opgenomen). De losse geluidsbestanden staan in `noten/`.
